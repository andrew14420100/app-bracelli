# Bracelli Club 0.6.1 — Download

Pacchetti completi delle Fasi 1–6, già pronti all’uso.

- **bracelli-club-plugin.zip**: plugin WordPress completo con PWA già inclusa. Installare da **Plugin → Aggiungi nuovo → Carica plugin**, attivare e aprire **Bracelli Club → Apri app**. Non servono npm o terminale.
- **bracelli-club-app.zip**: build PWA statica separata, comprensiva di HTML, CSS, JavaScript, manifest, logo, icone e service worker. Non installarla come plugin WordPress.
- **GUIDA-INSTALLAZIONE.html**: guida italiana; inclusa anche nei due ZIP.
- **checksums.json**: dimensioni e SHA-256 degli archivi.
- **verification.json / test-results.json**: verifiche degli archivi e test locali eseguiti.

Per scaricare: aprire uno dei file ZIP su GitHub e premere **Download raw** (icona di download). Evitare l’archivio generico **Code → Download ZIP**, che contiene la cartella del repository e non è direttamente installabile come plugin.

Il plugin è stato installato dallo ZIP su WordPress pulito. Testati PWA inclusa, API, richieste, SMTP locale, autorizzazioni, offline e permalink normali/semplici. Logo originale preservato. Nessuna password, account di test o database incluso.

Collaudare su un WordPress temporaneo separato. Nessun deploy in produzione o sul sito ufficiale. Installazione HTTPS sullo staging esterno e dispositivi Android/iPhone fisici restano da verificare.
